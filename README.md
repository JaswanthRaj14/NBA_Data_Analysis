# NBA_Data_Analysis
Python-based NBA dataset cleaning and preprocessing project using Pandas and NumPy for analysis-ready data preparation.

## 📌 Project Overview

This project focuses on cleaning, preprocessing, and preparing raw NBA dataset using Python for further analysis and visualization. The objective is to improve data quality by handling missing values, duplicates, inconsistent formats, and outliers, making the dataset suitable for business analytics and dashboard development.

## 🎯 Objective

* Transform raw NBA data into a clean and structured format
* Improve data accuracy and consistency
* Prepare dataset for analytical insights and visualization
* Apply real-world data preprocessing techniques


## 🛠 Tools & Technologies Used

* Python
* Pandas
* NumPy
* Jupyter Notebook


## 🔄 Data Cleaning Steps Performed

* Removed missing and null values
* Handled duplicate records
* Standardized column names and formats
* Converted data types for numerical analysis
* Outlier detection and treatment
* Feature selection and filtering
* Exported cleaned dataset for further use


## ✅ Output

* Generated cleaned NBA dataset ready for analysis
* Improved dataset reliability and consistency
* Prepared structured data for dashboard creation and reporting


## 📊 Business Impact

This cleaned dataset can be used to:

* Analyze player performance trends
* Identify top-performing players and teams
* Support data-driven sports analytics decisions
* Build interactive dashboards for insights
